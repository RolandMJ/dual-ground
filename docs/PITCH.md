# Dual Ground — Pitch Script

**Duration:** 2-3 minutes
**Format:** Live demo walkthrough

---

## Opening (15 seconds)

"Most people learn AI prompting by reading blog posts and then guessing. Dual Ground does it differently — you learn and build at the same time, and you leave with three things you can actually use."

## The Problem (20 seconds)

"There are plenty of tutorials about prompting, and plenty of playgrounds where you can type things in. But they're separate. You read something, then you go somewhere else to try it. By the time you start building, you've already forgotten half of what you read. And none of it is saved in a format you can reuse."

## The Solution (30 seconds)

"Dual Ground is a split-screen web app. On the left, you work through six focused modules about how Claude actually works — not marketing, not theory, just how the model processes your input and what you can control. On the right, you build two things in real time: a working prompt using colour-coded blocks, and a personal SKILL.md file — a reusable instruction set that Claude reads at the start of every conversation."

## The Flow (45 seconds — live demo)

*[Show the app. Click through Module 1 briefly.]*

"Each module ends with three quiz questions. When you answer them, the corresponding block types unlock on the builder side."

*[Answer the quiz, show blocks unlocking with the animation and toast.]*

"You're not just reading about roles and context — you're immediately building a role block and a context block with real content. The live preview shows your assembled prompt updating in real time."

*[Add a Role block, type something, show the preview.]*

"The skill blocks work the same way — Name, Description, Trigger, Steps, Notes. By the end, you have a complete SKILL.md file."

## The Output (30 seconds)

*[Click Finish & Reveal.]*

"When you're done, you get three outputs. First, your assembled prompt — ready to copy and use. Second, your SKILL.md file — download it, drop it into Claude Code, and it works. Third, your AI personality type — based on which block types you gravitated toward."

*[Show the archetype card.]*

"Are you an Architect who builds structured prompts? An Explorer who leads with examples? A Guardian who thinks about safety first? The card tells you, and gives you a personalised playbook for getting better."

## The Close (15 seconds)

"Dual Ground. Two paths, one session, three real outputs. Everything you build here is yours to keep and use immediately. No account required, no data collected, no paywall."

---

## Key Talking Points (if Q&A)

- **Built with vanilla JS** — no framework, no build step, loads instantly
- **All curriculum content is independently written** and cross-checked by the author against Anthropic's publicly available documentation
- **The SKILL.md format** is the same format Claude Code actually uses for skills
- **The archetype scoring** is based on actual block usage patterns, not a personality quiz
- **Designed for one session** — you can complete the whole thing in 30-45 minutes
- **Works offline** once loaded — no API calls, no backend
