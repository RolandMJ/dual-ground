Skill Blocks

New block types unlock as you complete modules and quizzes on the left.

Sample SKILL.md Structure
Name code-reviewer
Description Reviews code for bugs, security issues, and readability improvements.
Trigger When the user asks for a code review or shares a code snippet for feedback.
Steps 1. Check for bugs and logic errors. 2. Flag security concerns. 3. Suggest readability improvements. 4. Summarise findings.
Notes Be specific about line numbers. If code is fine, say so briefly rather than inventing issues.
Real-World Example: Meeting Notes Skill
Name meeting-notes
Description Turns rough meeting transcripts or bullet points into clean, organised meeting notes with action items.
Trigger When the user shares meeting notes, a transcript, or says "clean up these notes."
Steps 1. Identify the meeting topic and attendees if mentioned. 2. Organise points into clear sections. 3. Extract action items with owners. 4. Add a one-line summary at the top.
Notes Keep the original meaning — don't add information that wasn't discussed. If something is unclear, flag it with [unclear] rather than guessing.

Terminal Basics
lsList files in the current folder
cd folder-nameMove into a folder
cd ..Go back one folder
mkdir my-projectCreate a new folder
cat file.txtShow a file's contents
pwdShow where you are (current path)
cp file.txt copy.txtCopy a file
mv old.txt new.txtRename or move a file
rm file.txtDelete a file (careful — no undo)
clearClear the terminal screen
Git Essentials
git initStart tracking a project with git
git add .Stage all changes for commit
git commit -m "message"Save a snapshot with a description
git statusSee what has changed since last commit
git log --onelineSee recent commit history
git pushUpload commits to GitHub/remote
git pullDownload latest changes from remote
Claude Code Commands
claudeStart an interactive Claude Code session
claude -p "question"Ask a quick question without starting a session
claude -p "q" --output file.txtSave Claude's answer to a file
cat file | claude -p "analyse this"Pipe file contents into Claude
git diff | claude -p "review"Have Claude review your code changes
Inside a Claude Code Session
/initGenerate a CLAUDE.md for your project
/helpShow available slash commands
/clearClear conversation history
/costShow token usage and cost for this session
/compactCompress conversation to save context space
/configOpen Claude Code settings
Useful Combos
mkdir project && cd project && claudeCreate folder, enter it, start Claude
claude -p "explain this codebase"Quick project overview
claude -p "find bugs in server.js"One-shot bug scan
npm test | claude -p "fix failing tests"Pipe test output for Claude to fix
